# Contributing

This is a reference implementation; contributions that improve clarity, tests and safety are welcome.

1. Read `AGENTS.md` and `docs/CODING_STANDARDS.md`.
2. Run `python -m unittest discover -s tests -q` before and after your change and include the real output summary in the PR.
3. Keep PRs narrow. One behaviour per PR, with a regression test.
4. Never include real hostnames, addresses, accounts, tokens, personal data, fonts, logos or third-party source.
5. Do not change `LICENSE`. By contributing you agree your work is licensed GPL-3.0-or-later like the rest of the original source.
